# Kundana Rangineni — AI/ML Engineer Portfolio

## Publish with GitHub Pages

1. Create a new public repository named `kundana-portfolio`.
2. Upload `index.html` and `Kundana_Rangineni_Resume.docx`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`.
6. Click **Save**.
7. Your site should be available at:
   `https://kundana2508.github.io/kundana-portfolio/`
